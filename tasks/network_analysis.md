# 网络使用情况检查分析任务 - Network Usage Analysis

## 概述
分析整个 AgentGeeX 网络的使用情况，包括各主机资源消耗、各节点运行状态、任务负载分布，为全局调度优化提供依据。

## 分析维度

### 1. 主机资源使用率
- 各主机的 CPU/内存/磁盘使用率排名
- 空闲资源汇总
- 超载节点告警

### 2. 任务负载分布
- 各主机上的活跃任务数
- 任务类型分布
- 执行时长统计（平均/最大/最小）
- 失败率统计

### 3. 网络拓扑健康
- 节点间网络延迟
- 在线/离线节点列表
- 节点可达性检查结果

### 4. 资源调度建议
- 负载不均衡分析
- 建议迁移的任务
- 建议扩缩容的节点

## 数据来源
- `agx_host_inventory` — 主机注册信息
- `agx_task_execution` — 任务执行记录
- `agx_agent_registry` — Agent 分布情况

## 输出格式
返回 JSON 报告，包含摘要、各维度分析结果、异常列表和优化建议。
