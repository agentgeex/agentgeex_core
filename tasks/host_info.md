# 主机信息搜集任务 - Host Info Collection

## 概述
搜集当前主机的硬件和系统信息，为资源调度和负载均衡提供依据。

## 采集清单

### 1. CPU 信息
- 型号和架构
- 核心数（物理/逻辑）
- 当前使用率和负载
- CPU 频率

### 2. 内存信息
- 总内存
- 已用内存
- 可用内存
- Swap 使用情况

### 3. 磁盘信息
- 各分区挂载点
- 总容量
- 已用/可用空间
- 磁盘 I/O 负载

### 4. 网络信息
- IP 地址（内网/公网）
- 网卡速率
- 网络延迟（探测到其他节点）
- 带宽使用率

### 5. 系统信息
- 操作系统版本
- 内核版本
- 运行时长（uptime）
- 系统负载（load average）

## 输出格式
返回 JSON 对象，包含上述所有指标的当前值和时间戳。
