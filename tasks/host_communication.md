# 主机通信任务 - Host Communication

## 概述
负责主机与外部系统的通信，通过邮件、Telegram、飞书等渠道收发消息和告警。

## 通信渠道

### 1. 邮件（SMTP）
- 发送告警通知
- 发送定期报告
- 接收指令邮件
- 支持多邮箱配置

### 2. Telegram Bot
- 发送实时告警
- 接收查询指令
- 支持群组和私聊
- 消息格式：文本、Markdown

### 3. 飞书（Feishu/Lark）
- 发送消息卡片
- 创建日程提醒
- 群聊消息交互
- 多维表格读写

## 消息优先级
- **P0 紧急**：系统宕机、关键服务不可用 → 全渠道推送
- **P1 重要**：资源接近上限、任务失败 → 邮件 + 即时通讯
- **P2 一般**：任务完成、定期报告 → 按配置渠道通知

## 输出格式
返回发送结果，包含渠道、状态、消息ID和时间戳。
