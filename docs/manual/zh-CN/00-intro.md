# AgentGeeX 使用手册

AgentGeeX 是一套让多个 Agent 协作完成工作的系统：把主机登记进来，让 Agent 在上面运行，用项目和任务组织它们的工作，用执行记录追踪每一次结果。

## 这本书的组织方式

全书按**创建路径**排列，不是按内部数据结构排列。从一台机器开始，到能自动跑完一件复杂工作为止。

| 章 | 内容 | 回答的问题 |
|---|---|---|
| 第 1 章 主机 | 主机如何登记、上面跑什么进程 | 我有一台机器，怎么让它跑 Agent |
| 第 2 章 Agent | 角色如何创建、部署、迁移 | 谁来做这些事 |
| 第 3 章 项目 | 如何组织成员与权限边界 | 一堆 Agent 怎么管 |
| 第 4 章 任务 | 能力如何定义与发布 | 这些事怎么被描述成可执行单元 |
| 第 5 章 任务执行 | 一次执行如何流转、卡住谁管 | 派出去之后发生了什么 |
| 第 6 章 快捷指令 | 常用操作如何固化成入口 | 天天打的指令怎么省 |
| 第 7 章 会话与助理 | 执行落在哪里、分身如何并行 | 上下文怎么不打架 |
| 第 8 章 计划 | 多步骤工作如何自动编排 | 十几步的活怎么自己走完 |

## 核心概念

| 概念 | 说明 | 章节 |
|---|---|---|
| 主机 | 一个可派发任务的 Agent 运行时。一台机器上可以运行多个主机 | 1 |
| Agent | 具有身份、角色、归属项目与所在主机的执行单元 | 2 |
| 项目 | Agent 的组织单位与权限边界 | 3 |
| 任务 | Agent 具备的能力，由说明书与结构化属性组成 | 4 |
| 执行 | 任务的一次具体运行，含指令、结果、耗时与状态 | 5 |
| 快捷指令 | 带参数的固化入口，把常用操作变成一次调用 | 6 |
| 会话 | 执行的落点单元，一条执行必须落在某个会话中 | 7 |
| 助理 | Agent 自己的分身，同能力、独立会话、独立文件区 | 7 |
| 计划 | 把多个执行按依赖关系编排起来，由看门狗推进 | 8 |

## 基本关系

```
主机  承载  Agent
项目  组织  Agent
Agent 具备  任务
任务  产生  执行
执行  落在  会话
计划  编排  执行
```

各层之间没有替代关系，缺一层就有对应的能力缺失：没有主机则无法运行，没有项目则无法划权限，没有任务则无法复用行为，没有执行则无法追溯。

## 阅读建议

第一次使用按章节顺序读，第 4、5 章是全书的核心概念分界，建议读完再动手。已经理解概念、只需要查参数时，直接查阅各章的属性表与 MCP 方法表。

各章均依次讲清：这是什么、有哪些属性、怎么操作、什么情况不适用。查找具体字段时看正文中的折叠区，那里是完整的字段定义。
