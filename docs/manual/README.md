## 写作约定

1. **陈述句。** 讲清楚这个东西是什么、怎么用、参数怎么填、为什么这样做。不用设问、不用引导语、不用读完自测。
2. **正文讲概念与判据，不默认吐 SQL。** 需要精确到列的，收进 `<details>` 折叠区。
3. **每章末尾列出不适用的情况。** 例子要能跑，数字要查过。
4. **表格统一为「名称 | 说明」式**，说明列用技术描述，不留空表头。
5. **讲结构的地方必须同时说明操作入口。** 凡涉及表、字段、落点，同节内写明日常通过 MCP 方法操作，不需要手写。
